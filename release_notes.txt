Release Notes
==========================================
V1.0.5 (2025-12-05 )
1. Fix some issues.
2. Upgraded alicloud sdk to 1.6.6.
3. Added support for RTT v5.0.1.
4. Added support for SoftAP provisioning.
5. Upgraded CMSIS-ARM to v6.2.0 and DSP-Lib to 1.16.2.
6. Upgraded LwIP from v2.1.2 to v2.2.0.
7. Upgraded MbedTLS from v2.17.0(ROM) to v3.6.5(Flash).
8. Upgraded FreeRTOS from v10.3.1 to v10.5.1.

==========================================
V1.0.4 (2024-02-06 )
1. Improve compatibility with AP.
2. Support MQTT-3.1.1 and MQTT-5.0
3. Support build under Linux.

==========================================
V1.0.3 (2022-11-30)
1. Update Firmware_library.
2. Improve robustness of AP mode.
3. Add new UART command:switch_image.

==========================================
V1.0.2 (2022-03-18)
1. Simplify development environment setup.
   Remove dependency on Python and remove automatic download after compilation.
2. Support LWIP IPV6 for STA mode.
3. Add new UART command to enable bandwidth 40M support.
4. Fine tune RF and update RF control parameters.

==========================================
V1.0.1 (2022-01-20)
1. Add UART configuration for GD32W515P-EVAL board.
2. Support more types of GD QSPI FLASH chips.

V1.0.0 (2021-11-30)
1. First release.
